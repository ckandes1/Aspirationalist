# Aspirationalism

Aspirationalism is a methodology under development through the Aspirationalist Project.

This topic is where Keith Andes defines, tests, improves, and eventually formalizes what Aspirationalism means.

## Working definition

Aspirationalism is the optimistic belief that humanity has the capacity and responsibility to influence the future, paired with the desire to productively contribute to making that future better.

The working definition is intentionally unfinished. It should improve over time as the project clarifies the belief system, methodology, language, practices, and artifacts around it.

## Current shape

Loosely, Aspirationalism starts from these beliefs:

- The future can be better if people choose to make it better.
- Humanity has real capacity to solve problems, build better systems, and improve life over time.
- Optimism matters because people need to believe progress is possible before they commit effort to it.
- Contribution matters because belief without action does not build anything.
- Individual action matters, but the largest problems require people to come together.
- The productive stance is: we can build a better future, so let's go build it.

## What this topic covers

This topic should collect thinking about:

- the working definition of Aspirationalism;
- Aspirationalism as a methodology;
- the beliefs, principles, and practices behind the Aspirationalist Project;
- the relationship between optimism, responsibility, contribution, and action;
- how individuals and teams can productively contribute to a better future;
- how systems of work can either enable or constrain human potential; and
- what future artifacts, frameworks, manifestos, or tools should emerge from the project.

## Content maturity

`raw → frameworks → assets`

- **raw/** contains early definitions, stream-of-consciousness notes, unresolved beliefs, and exploratory thinking.
- **frameworks/** contains named concepts and methodology pieces that have been developed enough to use deliberately.
- **assets/** contains public-facing artifacts, guides, manifestos, or tools designed for other people to use.

## Boundary

This topic should not pretend Aspirationalism is already fully defined.

The point of the Aspirationalist Project is to define it better over time. Early material should preserve uncertainty, competing definitions, rough language, and the energy behind the idea instead of prematurely over-polishing it.
