## Purpose

This file connects the MQ Package repository to the unstructured source assets collected in NotebookLM.

NotebookLM is the intake and exploration workspace. It can hold source assets before they are organized, reconciled, or converted into durable project material.

GitHub is the authoritative project record once material has been processed.

## Authority rule

Use this progression:

`NotebookLM intake → GitHub source → working → canonical → artifacts → distribution`

- **NotebookLM intake:** unstructured files, transcripts, decks, notes, prompts, and exploratory synthesis.
- **GitHub source:** preserved evidence and consolidated source records close to the original material.
- **Working:** explicit synthesis, decisions, alternatives, drafts, and unresolved questions.
- **Canonical:** approved operating guidance and the maintained MQ system.
- **Artifacts:** polished tools, decks, playbooks, scorecards, and other outputs intended for use.
- **Distribution:** LinkedIn posts, articles, newsletters, webinars, and other channels derived from the package.

NotebookLM content does not become canonical because it has been summarized or organized by an AI. Material must be deliberately processed into the appropriate GitHub stage.

## Intake record

When a NotebookLM item is processed, record:

- source name or recognizable description
- source type
- date or approximate period
- what it contributes
- whether it confirms, expands, or contradicts existing material
- confidentiality or licensing concerns
- destination file in GitHub
- processing status

Suggested statuses:

- **Unreviewed**
- **Reviewed, no repository change needed**
- **Added to source**
- **Converted into working material**
- **Promoted to canonical**
- **Used in artifact**
- **Deferred**
- **Excluded for confidentiality or licensing**
